# Vídeos institucionais

Envie manualmente para esta pasta os seis arquivos abaixo, mantendo exatamente estes nomes:

- `hsbe-video-01.mp4`
- `hsbe-video-02.mp4`
- `hsbe-video-03.mp4`
- `hsbe-video-04.mp4`
- `hsbe-video-05.mp4`
- `hsbe-video-06.mp4`

Formato recomendado: MP4 com vídeo H.264, resolução 1080 × 1920, 30 fps, áudio AAC, bitrate entre 4 e 6 Mbps, `faststart` e tamanho inferior a 25 MB.

O site acessa esses arquivos pelos caminhos públicos `/videos/hsbe-video-01.mp4` até `/videos/hsbe-video-06.mp4`. Se um arquivo ainda não estiver presente, o player mostra um aviso sem interromper a página.
