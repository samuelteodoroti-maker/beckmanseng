# Sincronização do projeto e preparação dos vídeos

## Objetivo
Preservar integralmente o site atual, concluir a estrutura pública dos seis vídeos e sincronizar o projeto com um repositório GitHub na conta Teodoro-Sam.

## Alterações
- Manter todas as páginas, conteúdos, imagens, estilos e funcionalidades atuais sem mudanças visuais.
- Garantir que o player use exclusivamente os caminhos públicos `/videos/hsbe-video-01.mp4` até `/videos/hsbe-video-06.mp4`.
- Manter `controls`, `playsInline` e `preload="metadata"`, carregando somente o vídeo aberto pelo visitante.
- Manter uma mensagem visual amigável quando o arquivo correspondente ainda não existir.
- Documentar na pasta `public/videos` os seis nomes exatos e as recomendações de formato.
- Validar a página inicial e a página de vídeos sem modificar o design.

## Sincronização
- Confirmar a autorização do Git Sync para a conta Teodoro-Sam pelo fluxo do Lovable.
- Sincronizar o estado completo atual na branch principal `main` do repositório criado pelo Lovable.
- Ao concluir, informar o nome e endereço do repositório, a branch sincronizada, a pasta preparada e os MP4 ainda pendentes de envio manual.

## Observação técnica
O repositório Git interno já está limpo e o build atual está aprovado. A sincronização externa depende da autorização da conta GitHub no fluxo de Git Sync do Lovable; ela não será substituída por uma integração de API dentro do site.
